# IND-SKC-Materials - SKC 반도체 소재 (CMP 패드)

## CMP 패드 제품

SKC는 반도체 웨이퍼 표면을 물리, 화학 반응으로 연마해 반도체 웨이퍼 표면을 평탄하게 만드는 CMP(Chemical Mechanical Polishing) 패드를 생산합니다. 3D 낸드플래시 생산 증가에 따라 수요가 증가하는 소모성 자재입니다.

## 주요 제품 라인업

| 제품 | 특징 |
|------|------|
| **HD-319B** | 범용 Hard Type |
| **HD-500C** | 결함/스크래치 저감형 Hard Type |
| **SD-138B** | 결함/스크래치 저감형 Semi-Hard Type |
| **HD-300D** | 200mm 웨이퍼용 Hard Type |

## 패드 종류별 선택 기준

- **Hard Type**: 평탄화 효율이 높음, 막질 평탄도 우수
- **Semi-Hard Type**: defect·scratch 저감에 유리, 박막 보호
- **Soft Type**: STI(Shallow Trench Isolation) 등 selective polishing에 사용

## 운영 시사점

- 패드는 CMP 결과(MRR, uniformity, scratch)에 직접 영향
- 패드 마모 → 슬러리 분포 변화 → 산포 증가
- 제품 종류·막질·노드에 따라 패드 선택이 결정적

## 용도

반도체 웨이퍼 표면 연마 공정에 적용되어 반도체 집적도 향상을 지원합니다.
