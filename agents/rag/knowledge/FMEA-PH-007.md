# FMEA-PH-007 — Photo 공정 실패 모드 분석

## 대상

Photo / Lithography 공정의 주요 실패 모드와 원인, 영향, 검출 방법을 정리합니다.

## 실패 모드

### 1. CD 산포 증가

- 잠재 원인: 투영 렌즈 오염, 노광 에너지 드리프트, 스테이지 진동
- 영향: 후공정 Etch 단계의 트렌치 깊이 편차 확대, 수율 손실
- 검출: SPC 기반 CD-X 산포 모니터링, 헤이즈 센서

### 2. 오버레이 오차

- 잠재 원인: 스테이지 진동, 정렬 마크 손상
- 영향: 패턴 정합 불량
- 검출: 오버레이 계측, 진동 센서

### 3. 포커스 편차

- 잠재 원인: 웨이퍼 평탄도 불량, 척 오염
- 영향: 패턴 해상도 저하
- 검출: 포커스 계측

## 우선순위

CD 산포 증가는 발생 빈도와 후공정 영향이 모두 커 최우선 관리 대상입니다. 원인
중 렌즈 오염은 PM 주기와 강한 상관이 있어 정비 이력 확인이 우선입니다.
