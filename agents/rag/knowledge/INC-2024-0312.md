# INC-2024-0312 — Photo 렌즈 오염으로 인한 CD 산포 증가

## 분류

- 유형: 공정 인시던트
- 공정: Photo / Lithography
- 사업부: 메모리 1동
- 발생일: 2024-03-12

## 증상

노광 공정에서 CD-X 산포가 관리 한계를 초과하였습니다. 동일 스캐너에서 처리된
연속 로트에서 CD 균일도가 점진적으로 악화되는 양상이 관측되었습니다.

## 원인

투영 렌즈 표면 오염으로 확인되었습니다. 직전 PM(예방 정비) 이후 14일이 경과한
시점이었으며, 헤이즈 센서 측정값이 평소 대비 18% 상승해 있었습니다.

## 조치

- 렌즈 긴급 PM 투입 (약 2시간 소요)
- 영향 로트 후공정 진입 보류
- PM 주기를 30일에서 21일로 단축 권고

## 재발 방지

헤이즈 센서 임계값을 신설하고, 임계 초과 시 자동 알람이 발생하도록 모니터링을
강화하였습니다.
