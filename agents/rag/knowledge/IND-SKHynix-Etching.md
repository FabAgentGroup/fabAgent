# IND-SKHynix-Etching - SK하이닉스 식각 공정 가이드

## 식각 공정의 원리

식각은 반도체 제조의 핵심 공정으로, 동판화를 만드는 과정과 유사합니다. 웨이퍼 위의 특정 부분을 조각하여 원하는 패턴을 형성합니다.

## 식각 방식의 분류

### 습식 식각
- **장점**: 속도가 빠르고 높은 생산성 제공
- **단점**: 정밀도 낮음, 폐용액 처리로 환경 부담 증가

### 건식 식각
- **장점**: 높은 정밀도, 기체 배기로 환경 영향 최소화
- **단점**: 느린 식각 속도, 폴리머 잔유물 발생

### RIE (Reactive Ion Etching)
현재 가장 활발히 사용되는 방식으로, 물리적·화학적 방식을 결합하여 막에 데미지를 최소화하면서 이방성 식각을 유도합니다.

## 식각 공정의 핵심 요소

| 요소 | 설명 |
|------|------|
| **선택비** | 두 막의 식각률 차이를 크게 하여 원하는 막만 선택적으로 식각 |
| **식각률** | 분당 식각 깊이 (Å, nm, μm 단위) |
| **종횡비(Aspect Ratio)** | 갭의 높이/밑변 길이 (높을수록 정밀도 향상) |
| **종말점(End-Point)** | 식각 종료 시점 결정 |

## 주요 식각 결함

- **Over Etch**: 계획 깊이보다 과도하게 식각 → 하부 막 손상
- **Under Etch**: 불완전한 식각으로 잔유물 남음 → 다음 공정(이온 주입 등) 방해

최근 추세는 습식보다 건식 또는 혼합 방식을 선호합니다.
