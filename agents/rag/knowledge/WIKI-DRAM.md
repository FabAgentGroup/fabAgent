# WIKI-DRAM - 동적 RAM(Dynamic Random Access Memory)

## 기본 구조

동적 RAM은 각 데이터 비트를 하나의 트랜지스터와 하나의 커패시터로 구성된 메모리 셀에 저장합니다. 커패시터의 충방전 상태가 0과 1을 나타내며, 전하가 점차 누설되므로 주기적인 새로고침이 필수입니다.

## 작동 원리

DRAM 읽기는 다음 단계를 거칩니다:

1. 감지 증폭기 분리 후 비트라인을 균등한 전압으로 사전충전
2. 워드라인을 높게 구동하여 저장 커패시터를 비트라인에 연결
3. 미미한 전압 차이를 감지 증폭기가 논리 신호로 증폭
4. 감지된 데이터로 저장 셀을 자동으로 새로고침

쓰기는 원하는 전압 상태로 감지 증폭기를 강제하여 비트라인이 셀 커패시터를 충방전하도록 합니다.

## 새로고침 요구사항

제조업체 표준(JEDEC)에 따라 각 행을 64ms 이내로 새로고침해야 합니다. 시스템은 일괄 새로고침 또는 순차 새로고침 방식을 선택할 수 있습니다.

## 주요 설계 변수

현대 DRAM 셀은 일반적으로 **6~8 F²** 크기이며(F는 최소 특징 크기), 다음 두 가지 커패시터 구조가 주류입니다:

- **스택형(Stack)**: 기판 위에 구성되어 제조가 용이
- **트렌치형(Trench)**: 기판 내에 매립되어 면적 효율성이 우수

## 주요 결함

- **로우 해머(Row Hammer)**: 한 행의 반복적인 접근이 인접 행의 데이터를 손상시키는 문제. 2014년 분석에서 상용 DDR3 칩도 취약함이 확인됨
- **리프레시 누락**: refresh interval 초과 시 데이터 손실
- **공정 결함**: 커패시터 누설, 트랜지스터 leak로 retention time 단축

## 공정 측면

DRAM은 1T1C 셀이 핵심이므로 다음 공정이 결정적:
- **딥 트렌치 식각**: 트렌치형 커패시터 형성
- **HKMG (High-K Metal Gate)**: 누설 감소
- **CMP**: 다층 평탄화 (저장 노드 평탄화 중요)
