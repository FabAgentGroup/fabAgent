# D16: 운영자 결정 자가학습 루프 측정

운영자 승인 분석이 INC-AUTO 문서로 knowledge에 기록되어, 향후 유사 알람의
retrieval을 실제로 개선하는지 측정합니다. 운영자 지식이 시스템 지식으로
즉시 반영되어 actionable해지는지를 정량 확인합니다.

## 실험 설정

- 코퍼스에 없던 해결 인시던트 5건 (공정별 고유 증상·해결책)
- 기록 전/후 동일 증상 쿼리로 retrieval, 해결 문서의 순위 비교
- retrieval: keyword 백엔드(로컬·결정론), top-3, 임시 문서는 측정 후 정리

## 결과

|---|---|
| 기록 전 retrieval 성공률 | **0%** (해당 지식 부재) |
| 기록 후 hit@3 | **80%** |
| 기록 후 MRR | **0.50** |

| 인시던트 | 공정 | 기록 전 순위 | 기록 후 순위 |

## 결론

- 기록 전에는 해당 해결책이 코퍼스에 없어 retrieval 불가(0%)
- 운영자 승인 즉시 INC-AUTO 기록 -> hit@3 80%, MRR 0.50로 상위 retrieval
- 운영자 결정이 시스템 지식으로 폐루프 반영됨을 정량 확인
- 보류·거절 사유는 감사 로그(core/audit.py)에 구조화 수집되어 추가 학습 신호로 활용 가능
